## 二、交付物清单

### 2.1 项目脚手架
- Vue 3.4 + Vite 5.4 + ECharts 5.5 + Axios 1.7
- 开发服务器：`npm run dev`（端口 5173，代理 /api → 后端 8000）
- 构建产物：`frontend/dist/`（gzip 后 ~400KB）

### 2.2 全局布局（`App.vue`）
- 侧边栏：Logo + 股票搜索框 + 六页导航 + 重算耗时指示
- 主内容区：根据选中页渲染对应组件
- 错误横幅 + 加载状态 + 空状态

### 2.3 六页工作台
| 页面 | 组件 | 功能 |
|------|------|------|
| 01 数据总览 | Overview.vue | 公司信息 + 质量报告 + 损益表 + 资产负债表 |
| 02 假设参数 | Assumptions.vue | WACC 参数 + 预测假设 5×6 矩阵 + DCF 终值参数 |
| 03 DCF 估值 | DCFView.vue | Gordon/Exit 双结果 + UFCF 现值表 + 敏感性热力图 |
| 04 可比公司 | CompsView.vue | 四路估值 + 倍数统计表 + 箱线图 |
| 05 SOTP | SOTPView.vue | 三情境卡片 + 分部贡献表 |
| 06 汇总看板 | SummaryView.vue | 加权中枢 + 模型明细 + 足球场图 |

### 2.4 ECharts 图表
| 图表 | 组件 | 实现 |
|------|------|------|
| 敏感性热力图 | Heatmap.vue | heatmap series + visualMap 四色渐变（红→黄→绿→青） |
| 乘数箱线图 | BoxPlot.vue | boxplot series（Min/P25/中位/P75/Max） |
| 足球场图 | FootballField.vue | custom series（区间条 + 中点圆）+ markLine（现价/中枢虚线） |

### 2.5 即时重算逻辑（`store.js`）
- `scheduleRecalculate()` — 300ms debounce 防抖
- 修改任意假设 → 更新 `state.assumptions` → 触发 `POST /api/recalculate` → 更新 `state.result`
- 重算耗时显示在侧边栏底部

### 2.6 Linear 深色主题（`style.css`）
- 背景：#0a0a0b / #111113 / #18181b 三级
- 文字：#f4f4f5 / #d4d4d8 / #a1a1aa / #71717a 四级
- 强调色：#5eead4（青色）
- 字体：等宽 JetBrains Mono（数据）+ 系统无衬线（文本）
- 玻璃态卡片：1px 半透明边框 + 8px 圆角
