## 二、交付物清单

### 2.1 估值编排器（`app/api/orchestrator.py`）
- `run_full_valuation(params)` — 接收完整假设包，串联 M1 全部模块：
  - WACC → Forecast → DCF (Gordon + Exit + 敏感性矩阵)
  - Comps (peers → 4路倍数 + consensus)
  - SOTP (segments → 3情境 + 敏感性矩阵)
  - Summary (5模型加权 + 自降级 + 评级)

### 2.2 FastAPI 路由（`app/api/routes.py`）
| 路由 | 方法 | 功能 |
|------|------|------|
| `/api/analyze` | POST | 抓取财报 → 标准化 → 自动假设 → 引擎全跑 → 完整估值结果 |
| `/api/recalculate` | POST | 传入完整假设包 → 引擎重跑 → 新结果（不抓取） |
| `/api/comps/pool` | GET | 获取预设可比公司池 |
| `/api/projects` | POST | 保存项目（新建或更新） |
| `/api/projects` | GET | 列出全部项目 |
| `/api/projects/{id}` | GET | 载入单个项目 |
| `/api/projects/{id}` | DELETE | 删除项目 |
| `/api/health` | GET | 健康检查 |

### 2.3 SQLite 项目存取（`app/api/store.py`）
- `projects` 表：id (uuid) / name / ticker / market / created_at / updated_at / payload (JSON)
- 使用 stdlib sqlite3，无 ORM 依赖
- DB 路径：`backend/data/projects.db`

### 2.4 FastAPI 应用入口（`app/api/main.py`）
- CORS 中间件（允许前端 5173 端口）
- 启动：`uvicorn app.api.main:app --reload --port 8000`
