## 二、交付物清单

### 2.1 标准科目定义（`app/data/accounts.py`）
- 损益表科目：revenue / gross_profit / selling_expense / admin_expense / ebit / da / ebitda / net_income / eps_diluted
- 资产负债表科目：cash / debt / shares_diluted
- 每股科目标记 `per_share=True`，不参与 unit_scale 缩放

### 2.2 科目映射器（`app/data/mapper.py` + `config/mapper_{hk,us}.yaml`）
- **同义词匹配**：normalize 去空格 + 全半角统一 + lower
- **IFRS-16 口径**：`debt = 短期贷款 + 长期应付款 + 融资租赁负债(流动) + 融资租赁负债(非流动)`
- **多科目累加**：同一标准科目多个来源科目自动求和
- **推导规则链**：gross_profit → ebit → ebitda → net_income 互推；da 独立推导
- **eps 反推股数**：`shares_diluted = net_income / eps_diluted`（当 balance 无直接股数科目时）
- **per-share 科目不缩放**：eps_diluted 是每股单价，跳过 unit_scale（关键 bug 修复点）

### 2.3 质量检查器（`app/data/quality.py`）
- 缺失科目检测（required_by_model：dcf/comps_pe/comps_ev_ebitda/comps_ev_ebit/sotp）
- 降级建议（亏损剔 P/E、负 EBITDA 剔乘数）
- 币种混合警告
- health 分级：good / partial / poor

### 2.4 Provider 抽象层（`app/data/providers/`）
- `FinancialProvider` 抽象基类 + `fetch_with_fallback` 多源切换
- `AkshareProvider`：港股长表解析（`stock_financial_hk_report_em`），AMOUNT×1e-6 → 百万元
- `YFinanceProvider`：美股财报（`yfinance.Ticker.financials`）
- `ManualProvider`：手动数据兜底

### 2.5 分析流水线（`app/data/pipeline.py`）
- `analyze(ticker, market)` → 抓取 → 标准化 → 质量检查
- `build_engine_inputs(std)` → 引擎输入桥接（shares/price/cash/debt/net_debt/history）
- `build_forecast_assumptions(std)` → 自动假设生成（CAGR + 毛利率均值回归）

### 3.2 DCF 端到端（自动假设 + 范例对齐 WACC）
| 输出 | 真实抓取 | 范例 | 偏差 |
|------|---------|------|------|
| WACC | 9.1875% | 9.7951% | 0.61pp（beta=1.10 对齐，差异来自 weight_equity） |
| EBITDA Y5 | 34,517.21 | 39,816.03 | -13.3%（自动毛利率向均值回归） |
| PV(预测UFCF) | 76,293.17 | 83,654.69 | -8.8% |
| **DCF Gordon 每股** | **¥252.43** | **¥273.42** | **7.68%** ✅ |
| DCF Exit 每股 | ¥284.99 | ¥370.75 | 23.13% |

**结论**：Gordon 偏差 7.68% < 15% 门禁，✅ 通过。差异来源是自动生成的预测假设（growth/gross_margin/da_pct/capex_pct 用默认值）vs 范例精调假设，属预期行为。Exit 偏差较大因 EBITDA Y5 自动假设偏低，前端用户可手动修正假设收敛到范例值。

### 3.3 关键 bug 修复记录
- **eps_diluted 缩放 bug**：`eps_diluted` 是每股单价，被误乘 `unit_scale=1e-6` 导致 `shares_diluted = net_income / eps` 被放大 1e6 倍，DCF price=0.0。修复：per_share 科目跳过 unit_scale。修复后 92 测试全绿，真实 DCF 端到端跑通。
